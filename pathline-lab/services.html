Sample types

What the lab tests.

  • Blood tests

    Common examples
    Complete blood count, blood sugar, HbA1c, lipid profile, thyroid, liver and kidney function tests.
    Collection note
    Some tests need fasting. See the notes on the Book a Test page.

  • Urine tests

    Common examples
    Urine routine and microscopy, urine culture.
    Collection note
    A first-morning, midstream sample in a sterile container is usually preferred.

  • Stool tests

    Common examples
    Stool routine examination, stool culture.
    Collection note
    Use the clean container from the lab and bring the sample in fresh.

  • Sputum tests

    Common examples
    Sputum examination, as advised by your doctor.
    Collection note
    An early-morning sample coughed up from deep in the chest, not saliva.

  • Semen analysis

    Common examples
    Semen analysis.
    Collection note
    Usually 2–7 days of abstinence. The lab explains collection and how soon the sample must reach them.

  • Culture tests

    Common examples
    Urine, stool, blood, pus and swab cultures.
    Collection note
    Ideally collected before antibiotics, if your doctor agrees. Results take longer than routine tests.
